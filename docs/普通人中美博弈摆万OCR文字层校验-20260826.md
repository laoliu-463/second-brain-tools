### 工作流

1. **P0-1** 列出 5 份 PDF 与文字层路径。
2. **P0-2 / P0-2b / P0-2c** 原页以 2x 渲染 PNG（`page1-{二,三,四,五,六}.png`，1,191×17,789 至 1,624×24,140）；native_chars 全部为 0，确认纯图片页；Tesseract chi_sim+eng（`--psm 4`）抽取 OCR 候选（`ocr-{二,三,四,五,六}.txt`，每页 6,000+ 字符）。
3. **P0-3a** 定位截断锚点 → 抽取截断后 OCR 文本为 `supplement-{二,三,四,五,六}.txt`。
4. **P0-3b** `cleanup.py` 应用高频 OCR 错字映射初步校对 → `supplement-clean-{二,三,四,五,六}.txt`（清理后 1,129—2,137 字符）。
5. **P0-3c** 备份原层到 `backups/` → 更新 frontmatter（status/extraction_method/text_chars/patched/patch_method/patch_evidence/patch_draft/patch_log/patch_note）→ 在正文末尾用 `<!-- PATCH 2026-08-26 ... -->` 标记追加补文段。
6. **P0-4** 重算 SHA-256、汇总写入 `final-hash-check.json`、本节报告追加、`log.md` 追加。
