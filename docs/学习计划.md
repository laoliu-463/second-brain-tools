# 学习计划

> 本文档用于规划95篇文章的学习进度，并验证 EverMe 记忆系统的功能。

## 总体目标

- 系统学习55篇人智文章 + 40份大小课课程
- 验证 EverMe 记忆系统的检索、保存、关联功能
- 建立跨会话的学习进度追踪机制

## 记忆系统验证结果

### ✅ 已验证功能
- **检索功能**：mem_search 成功命中相关文章内容
- **关联检索**：对话记忆从2条增加到5条，系统在学习过程中自动记录
- **知识库命中**：每次检索都能准确命中95篇知识库中的相关内容

### ⚠️ 待验证功能
- **记忆保存**：mem_save_turn 返回 `saved: false`，需要进一步排查
- **跨会话持久化**：需要在新会话中验证记忆是否保留
- **进度追踪**：需要建立长期学习进度追踪机制
